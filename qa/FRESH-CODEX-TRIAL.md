# 无历史上下文 Codex 客户演练

日期：2026-11-03。首轮使用 v0.1.1（f478035），发现与修复纳入 v0.1.2。

## 方法

启动不继承主控对话历史的 Codex 子任务，业务资料仅提供本 GitHub 链接；另附隔离目录、权限和回报约束。主控扮演虚构客户，逐轮回答问题，没有把旧演练结果或预设答案告诉子任务。子任务从公开仓库下载指南，确认具体方案后才创建客户库并实际读写文件。首轮独立，后续按已定位问题及明确的修正规则定向回归；不是声称新版本又做过一遍全新的盲测。

## 实际客户旅程

1. 首次说明用途，并核实当前实际运行在 Mac 而非客户 Windows。
2. 三轮访谈：公司持续跟踪、行业专题、来源追溯；重点为分业务收入利润、液冷订单交付与投产。
3. 按客户要求，将系统目录改为“规则中心”、资料目录改为“研究证据”，出示准确路径、完整清单、页面样例和权限；等待确认。
4. 创建知识库。使用主控新提供的两份虚构纪要，不使用仓库内 A/B 示例。
5. 纪要 A 保留发言人和段落定位；预览经批准后保存原件、卡片、知识页和偏好。
6. 原文改名再次输入，命中同一指纹；卡片仍为 1 张，未新增登记或归档原件。
7. 按授权照录个人笔记。处理 B 的延期信息时先保存冲突候选，公司页保持逐字节一致。
8. 客户接受后保存试产计划的新旧日期及来源，不擅自下调交付预计或形成盈利判断；完成交接。

- 3亿元×25%=0.75亿元单列为口径一致前提下计算出的毛利额，不混同净利润。
- 设计年产能不冒充实际产量或利用率；试产预计不冒充已投产。

- 最终2份登记、2张卡片、2份归档原件；输入与原件字节一致。
