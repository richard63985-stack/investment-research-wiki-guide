# 模板使用说明

这些文件是待填写的模板，不是客户已经确认的内容。

- [个人配置](PROFILE.md)：访谈结果与默认差异，保存至客户库 00-系统/个人配置.md。
- [客户库 AI 入口](VAULT-AGENTS.md)：保存至客户库根目录 AGENTS.md。
- [材料登记](SOURCE-REGISTER.md)：统一记录材料身份、处理进度和重试状态。
- [页面模板](PAGES.md)：材料、公司、行业/专题、框架、审核与日志。
- [交接记录](HANDOFF.md)：设置和验收结果，保存在客户库 00-系统/交接记录.md。

填写后检查占位符、相对链接和日期。原始客户信息不回写到本通用仓库。
