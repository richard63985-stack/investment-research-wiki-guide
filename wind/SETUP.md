# 万得 API 接入教程：Windows + Codex

版本：0.1.7｜官方资料核对：2026-11-03｜状态：文档整理完成，客户 Windows 与账户未实测。

## 依据与适用范围

[官网 Client API 介绍](https://www.wind.com.cn/portal/zh/ClientApi/index.html)确认支持 Windows/Python，并提供终端命令 CG 的代码生成器。[官网下载中心](https://www.wind.com.cn/download.htm)提供终端安装包和[Windows 安装配置手册](https://www.wind.com.cn/windftp/wind.net/WFT_Windows_Configuration_Manual.pdf)。本教程以这条 Client API 路径为主，不假定所有“万得 API 账户”都是同一种产品。

公开手册是终端安装文档，不能证明当前每个 Python 版本兼容或 Python 插件的确切菜单位置。下面“检查、记录、验收”是本指南设计；接口参数以客户当前官方帮助/CG 生成为准。历史 [WindQuant 源码](https://github.com/WindQuant/Official/blob/master/WAPIWrapper/WAPIWrapperPython/WindPy.py)只用于交叉核对基本函数，不能作为当前安装包。

## 0. 先说明并判断接口

向客户说明：将检查接口产品、运行环境，完成连接与小范围取数，再保存后续使用说明。AI 能操作客户本机时自行检查；无法访问时给出逐步操作，不声称已经执行。

确认客户实际开通的产品：

- Wind 金融终端的 Client API/Python 权限：进入以下流程。
- 其他 HTTP/API Key、机构服务或官方 MCP 产品：读取该账户对应的当前官方接入文档，按其认证方式和端点另建分支；不能套用 WindPy，也不编造地址或凭据格式。
- 无法确认：先查看客户授权页面或终端帮助，仍不清楚时请客户确认产品名称/联系万得支持。不要索取密码或完整密钥。

完成条件：接入记录写明产品、官方文档来源和适用范围。

## 1. 检查 Windows 环境（只读）

确认实际在客户 Windows 本机运行，不在 WSL、容器或远端 Linux 中直接假定可访问本地组件。记录 Windows 版本/架构、Wind 版本与实际安装路径、Python 解释器路径/版本/位数、Codex 实际执行环境。

可在 PowerShell 中检查已有 Python；命令不存在时记录缺失，不把失败当成必须重装：

```powershell
Get-Command python, py -ErrorAction SilentlyContinue
py -0p
python -c "import sys,struct; print(sys.executable); print(sys.version); print(struct.calcsize('P')*8)"
```

可能存在多个 Python。后续所有检查和运行统一使用经确认的解释器完整路径。先用当前官方接口帮助确认支持范围，再决定是否安装或调整 Python；旧手册的最低版本不是当前推荐安装版本。

完成条件：解释器和 Wind 安装位置明确，或缺失组件已被准确列出。

## 2. 安装/登录终端

已安装并可用则复用。从官网下载中心进入当前 Windows 安装包和配套手册。按官方向导选择安装位置并安装，客户本人接受许可、处理管理员验证和登录。手册中的默认目录仅为示例，以实际路径为准。

企业网络连接问题按当前官方手册和机构 IT 要求处理。不要关闭安全软件或照搬旧 IP 清单绕过网络策略。

完成条件：客户能够打开终端并完成登录。该结果不代表 API 权限已验证。

## 3. 配置 Python 接口

在当前终端帮助中找到 Client API/Python 的安装或修复说明，并打开 CG 代码生成器。AI 应记录帮助文档标题/版本或位置，以及实际操作入口。

按当前官方说明，将接口配置到第 1 步选定的解释器。菜单名、安装脚本参数和位数要求必须现场核实；找不到时通过官方支持解决，不执行网上未经核实的旧版 installWindPy 命令，不从同名第三方包替代官方组件。

在 PowerShell 中以实际路径替换下方占位符再执行：

```powershell
& '<经确认的python.exe完整路径>' -c "import sys, WindPy; print(sys.executable); print(WindPy.__file__)"
```

完成条件：在目标解释器中导入成功，模块路径确实来自已确认的官方安装。只在另一解释器成功不能算通过。

## 4. 验证连接

先用当前帮助或 CG 核对连接调用。以下是基本 WindPy 示例，只在确认产品与函数适用后运行，保存为客户本机临时检查文件：

```python
from WindPy import w

result = w.start()
try:
    print("start_error_code:", getattr(result, "ErrorCode", None))
    connected = w.isconnected()
    print("connected:", connected)
    if getattr(result, "ErrorCode", None) != 0 or not connected:
        raise RuntimeError("连接未通过；保留原始错误结果并按当前官方帮助排查")
finally:
    w.stop()
```

完成条件：启动返回成功且连接状态为真。保留错误码及必要诊断，不输出或保存凭据。

## 5. 最小取数验证（不能跳过）

在 CG 中选客户有权限的一个证券、一个指标和少量历史日期。推荐先用已完成交易日的数据。让 CG 生成 Python 代码并核对字段含义、单位、日期和复权选项。

1. 保存 CG 生成的原始调用及选项说明，检查只包含读取数据操作。
2. 在同一个 Python 进程内启动连接，确认成功后执行生成的调用，结束时关闭连接。不要在第 4 步已关闭的进程外直接假设连接仍在。
3. 检查返回错误码、证券/字段/日期及数据维度；不能只看程序没报异常。
4. 检查空值和日期是否预期；至少与终端同口径数值核对一项，记录差异或一致结果。
5. 保存小样本、调用参数、取数时间与字段口径至客户私有目录。

本教程不硬编码财务字段或宏观指标 ID；由当前 CG/官方字段帮助确定，以免“代码跑通但口径错误”。通过后再做客户实际所需的一类数据；一项行情测试不能证明财务或宏观权限全部可用。

## 排错顺序

| 现象 | 首先核实 | 后续处理 |
|---|---|---|
| 找不到 WindPy | 解释器路径与模块路径 | 对同一解释器按官方方法配置，避免盲目重装 |
| 模块导入但组件加载失败 | 位数、组件版本、安装完整性 | 对照现行帮助修复，保留原错误 |
| 连接失败 | 登录状态、API 权限、网络 | 查当前官方错误说明；必要时联系支持 |
| 连接成功但取数失败 | 该字段/市场权限、参数、额度 | CG 重建小样本，分别验证 |
| 返回空数据 | 交易日、上市日期、报告期、字段适用性 | 查数据口径，空值不能替换成零 |
| 终端和 API 数字不同 | 单位、期间、复权、修订与时间戳 | 同口径重查后解释差异 |

不循环重试同一失败。保留进度与具体阻塞，后续从失败阶段恢复。官方支持入口见官网 Client API 页面。
